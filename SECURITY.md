# Security reporting

I AM MAGNANIMOUS WAY™ / Magnanimous AI is a proprietary platform. The
supported production version is the latest deployment from the `main` branch.

If you discover a potential security vulnerability, please report it privately
to **Godmattersinc@iammagnanimousway.com** with the affected feature, a safe
description, and a way to reproduce the problem. Do not publish security
details, credentials, personal data, or exploit instructions in a public issue.

We will review reports, investigate their impact, and prioritize fixes based
on severity. Please do not test with another user's account or data, disrupt
service, or access information that does not belong to you.

reuse proprietary source code. See [LICENSE](LICENSE).
