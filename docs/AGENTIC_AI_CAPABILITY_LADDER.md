# Magnanimous AI — Agentic Capability Ladder

Native Magnanimous learning and implementation map based on general industry skill areas; not a copy of any vendor curriculum or credential.

## 1. AI Foundations
AI/ML concepts, generative AI, responsible AI, workload selection, grounding, evaluation, privacy and safety.

## 2. Intelligent App Builder
AI-first applications with tool use, retrieval/grounding, workflow integration, governance, testing, deployment and application lifecycle management.

## 3. AI Agent Builder
Agents with goals, instructions, knowledge, tools, permissions, memory boundaries, handoffs, evaluations and multi-agent coordination.

## 4. Agent Administration
Access control, environment separation, connector governance, audit trails, monitoring, cost controls, data-loss prevention, incident response and lifecycle management.

## 5. Agentic Solution Architecture
Business requirements, architecture trade-offs, orchestration, human approval boundaries, reliability, observability, deployment and governance.

## 6. AI Transformation Leadership
Opportunity discovery, process redesign, adoption, workforce enablement, risk, ROI/cost measurement and responsible governance.

## Magnanimous implementation rules
- Magnanimous AI remains the brain, identity, memory owner, router and verifier.
- External models, APIs, low-code systems and vendors remain replaceable execution tools.
- Preserve existing working functionality; improvements are additive.
- Never claim an external certification unless actually earned.
- Learn concepts and open standards; do not copy proprietary course content, badges, source code or branding.
- Prefer native/free capabilities where practical.
- Consequential actions must pass authorization, tenant isolation, audit, consent and billing/cost controls.
- Agent learning retains provenance and freshness for changeable facts.
- Multi-agent work requires explicit handoff boundaries and verifiable outcomes.

## Build gates
1. Define the user/business outcome.
2. Select minimum necessary agent/tool permissions.
3. Ground with approved knowledge and traceable sources.
4. Add evaluation criteria and failure modes before release.
5. Test authentication, tenant isolation, tool authorization, injection resistance and cost limits.
6. Stage consequential actions for approval where required.
7. Log outcomes and feed privacy-safe lessons into Magnanimous learning.
8. Re-verify time-sensitive facts and external dependencies.
