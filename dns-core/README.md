# Magnanimous DNS Core

Magnanimous DNS Core is the platform-owned DNS/domain intelligence and guarded operations layer.

It provides native DNS lookup, resolver comparison, propagation analysis, DNSSEC visibility, reverse DNS, RDAP context, email-domain diagnostics, domain health analysis, Cloudflare DNS inventory/control through the existing confirmation gate, and an optional owner-only registrar adapter for domain/DNS account operations.

External resolvers and registrar providers are replaceable execution/data sources beneath Magnanimous AI. They do not own Magnanimous identity, memory, governance, or public branding.

See `ABSORPTION.md` and the DNS registrar documentation under `docs/` for architecture, safety boundaries, and verification procedures.
